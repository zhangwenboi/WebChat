# WebChat 项目总览

## 简介

WebChat 是一个 Chrome 浏览器扩展（Manifest V3），基于当前网页内容进行 AI 智能问答。它提取当前页面文本作为上下文，发送给 AI 模型进行分析和回答。

## 技术栈

- Chrome Extension Manifest V3
- 原生 JavaScript（无框架）
- marked.js（Markdown 渲染）
- Chrome Storage API（配置持久化）
- Fetch API + ReadableStream（流式请求）

## 功能特性

- 基于网页内容的智能问答
- 流式输出回答内容
- Markdown 格式渲染
- 支持自定义 API 和本地模型（Ollama）
- 上下文对话支持
- 自定义保留对话轮数
- 自定义系统提示词
- 可拖拽悬浮球和对话框
- Token 计数显示

## 数据流

```
用户输入问题
    ↓
content.js / popup.js 提取网页文本 (parseWebContent)
    ↓
chrome.runtime.connect 建立长连接 (answerStream)
    ↓
background.js 读取配置，构建请求
    ↓
fetch API (stream: true) → 流式请求 AI 服务
    ↓
逐块解析 SSE 响应
    ↓
port.postMessage → 实时推送到前端
    ↓
marked.js 渲染 Markdown → 显示在对话框中
```

## 网页内容抓取技术

使用 **DOM 克隆 + 文本提取** 方案：

1. `document.cloneNode(true)` 克隆整个文档（不影响原始页面）
2. 从克隆文档中移除无关元素：`<script>`、`<style>`、`<header>`、`<nav>`、`<footer>`
3. 获取 `<body>` 的 `innerText` 属性提取纯文本
4. 正则清理多余空白字符

这是一种轻量级的纯前端方案，无需依赖外部工具或 API。
