# 脚本自动化功能设计方案

## 需求概述

为 WebChat 扩展添加页面自动化脚本功能：
1. 支持自动录制用户操作 + 自然语言描述生成脚本（两种方式）
2. 调用大模型进行页面识别与内容读取
3. 脚本在浏览器内（content script）执行
4. 生成的脚本可导出到指定文件夹
5. 支持对脚本每个步骤进行手动修改
6. 支持多种动作类型（点击、输入、选择、滚动、等待、截图、拖拽、键盘、数据提取、条件分支、循环等）

## 三、支持的动作类型

| 类型 | 说明 | 关键参数 |
|------|------|----------|
| `click` | 点击元素 | selector, button(left/right/middle), clickCount |
| `dblclick` | 双击元素 | selector |
| `input` | 输入文本 | selector, value, clearBefore, inputType |
| `select` | 选择下拉框选项 | selector, value/text/index |
| `checkbox` | 勾选/取消复选框 | selector, checked(true/false) |
| `scroll` | 滚动页面或元素 | selector(可选), x, y, behavior |
| `hover` | 鼠标悬停 | selector, duration |

### 等待与导航

| 类型 | 说明 | 关键参数 |
|------|------|----------|
| `wait` | 等待元素出现/消失 | selector, state(visible/hidden/attached), timeout |
| `waitTime` | 固定等待时间 | duration(ms) |
| `waitNetwork` | 等待网络请求完成 | urlPattern, method, timeout |
| `navigate` | 页面导航 | url, waitUntil |
| `reload` | 刷新页面 | waitUntil |
| `back` | 浏览器后退 | — |
| `forward` | 浏览器前进 | — |

### 键盘操作

| 类型 | 说明 | 关键参数 |
|------|------|----------|
| `keypress` | 按键 | key(Enter/Tab/Escape等), modifiers(ctrl/shift/alt) |
| `hotkey` | 快捷键组合 | keys(['Ctrl', 'A']) |
| `type` | 逐字输入（模拟真实打字） | text, delay(每字延迟) |

### 高级交互

| 类型 | 说明 | 关键参数 |
|------|------|----------|
| `drag` | 拖拽元素 | sourceSelector, targetSelector/targetPosition |
| `upload` | 文件上传 | selector, filePath/fileContent |
| `screenshot` | 截图 | selector(可选), fullPage, format |
| `iframe` | 切换到 iframe 内操作 | selector, steps(子步骤) |

### 数据提取

| 类型 | 说明 | 关键参数 |
|------|------|----------|
| `extract` | 提取元素数据 | selector, attribute(text/href/src/自定义), saveTo(变量名) |
| `extractList` | 提取列表数据 | selector, fields[{name, subSelector, attribute}], saveTo |
| `extractTable` | 提取表格数据 | selector, headers(true/false), saveTo |

### 流程控制

| 类型 | 说明 | 关键参数 |
|------|------|----------|
| `condition` | 条件分支 | if(条件表达式), then(步骤数组), else(步骤数组) |
| `loop` | 循环操作 | type(count/while/forEach), count/condition/items, steps |

| `setVariable` | 设置变量 | name, value/expression |

### AI 辅助

| 类型 | 说明 | 关键参数 |
|------|------|----------|
| `aiRead` | AI 识别页面内容 | selector(可选), prompt, saveTo |
| `aiDecide` | AI 决策下一步操作 | context, options[], saveTo |
| `aiLocate` | AI 定位元素（自然语言描述） | description, action |

## 四、录制器设计 (Recorder)

### 工作原理

在页面中注入事件监听器，捕获用户操作并转换为脚本步骤。

### 监听的事件

```javascript
const RECORDED_EVENTS = [
    'click',        // → click/dblclick 步骤
    'dblclick',
    'input',        // → input 步骤
    'change',       // → select/checkbox 步骤
    'keydown',      // → keypress/hotkey 步骤（仅特殊键）
    'scroll',       // → scroll 步骤（节流处理）
    'submit',       // → click 步骤（定位提交按钮）
    'dragstart',    // → drag 步骤
    'drop'
];
```

### 元素定位策略

录制时为每个操作的目标元素生成稳定的选择器，优先级：

1. `id` — `#login-btn`
2. `data-testid` / `data-cy` — `[data-testid="submit"]`
3. `name` 属性 — `[name="username"]`
4. `aria-label` — `[aria-label="搜索"]`
5. 唯一 class 组合 — `.login-form .submit-btn`
6. CSS 路径 — `form > div:nth-child(2) > button`
7. XPath（最后手段）

### 录制优化

- **去重** — 连续的 input 事件合并为一个 input 步骤
- **智能等待** — 在页面导航后自动插入 wait 步骤
- **忽略噪音** — 过滤扩展自身 UI 上的操作
- **密码检测** — `type="password"` 的输入标记为敏感，不记录实际值

## 五、AI 脚本生成 (AI Agent)

### 工作流程

```
用户描述操作意图
    ↓
提取当前页面结构（简化 DOM）
    ↓
构建 Prompt（意图 + 页面结构 + 可用动作类型）
    ↓
调用大模型生成脚本 JSON
    ↓
验证脚本格式
    ↓
展示给用户确认/编辑
```

### 页面结构提取（给 AI 的上下文）

不发送完整 DOM，而是提取关键交互元素的简化结构：

```javascript
function extractPageStructure() {
    // 提取所有可交互元素
    const interactiveElements = document.querySelectorAll(
        'a, button, input, select, textarea, [role="button"], [onclick], [tabindex]'
    );

    // 生成简化描述
    return elements.map(el => ({
        tag: el.tagName,
        type: el.type,
        id: el.id,
        name: el.name,
        text: el.textContent.trim().slice(0, 50),
        placeholder: el.placeholder,
        ariaLabel: el.getAttribute('aria-label'),
        selector: generateSelector(el),
        visible: isVisible(el),
        position: el.getBoundingClientRect()
    }));
}
```

### Prompt 模板

```
你是一个浏览器自动化脚本生成器。根据用户的描述和当前页面结构，生成操作脚本。

## 当前页面信息
- URL: {{currentUrl}}
- 标题: {{pageTitle}}
- 可交互元素: {{interactiveElements}}

## 用户意图
{{userDescription}}

## 输出要求
生成符合以下 JSON 格式的脚本步骤数组：
[{id, type, description, params, options}]

支持的动作类型：click, input, select, wait, scroll, extract, assert, condition, loop...

## 注意事项
- 使用最稳定的选择器（优先 id > data-testid > name > aria-label）
- 在关键操作后添加适当的等待步骤
- 为每个步骤添加清晰的中文描述
```

### AI 页面识别（aiRead 动作）

执行脚本时遇到 `aiRead` 步骤：
1. 截取目标区域截图或提取文本
2. 将内容发送给大模型
3. 大模型返回结构化识别结果
4. 结果存入脚本变量供后续步骤使用

## 六、脚本执行器 (Executor)

### 执行流程

```javascript
class ScriptExecutor {
    async execute(script) {
        for (const step of script.steps) {
            // 1. 变量替换
            const resolvedStep = this.resolveVariables(step);

            // 2. 执行前回调（用于单步调试）
            await this.onBeforeStep(resolvedStep);

            // 3. 执行动作
            const result = await this.executeStep(resolvedStep);

            // 4. 执行后回调
            await this.onAfterStep(resolvedStep, result);

            // 5. 错误处理
            if (result.error) {
                await this.handleError(resolvedStep, result);
            }
        }
    }
}
```

### 执行模式

| 模式 | 说明 |
|------|------|
| `run` | 连续执行所有步骤 |
| `debug` | 单步执行，每步暂停等待确认 |
| `stepOver` | 执行当前步骤后暂停 |

### 元素操作实现

```javascript
// 点击
async function executeClick(params) {
    const element = await waitForElement(params.selector, params.timeout);
    element.scrollIntoView({ behavior: 'smooth', block: 'center' });
    await sleep(100); // 等待滚动完成

    // 模拟真实点击事件序列
    element.dispatchEvent(new MouseEvent('mousedown', { bubbles: true }));
    element.dispatchEvent(new MouseEvent('mouseup', { bubbles: true }));
    element.dispatchEvent(new MouseEvent('click', { bubbles: true }));
}

// 输入
async function executeInput(params) {
    const element = await waitForElement(params.selector);
    element.focus();

    if (params.clearBefore) {
        element.value = '';
        element.dispatchEvent(new Event('input', { bubbles: true }));
    }

    // 逐字输入模拟
    for (const char of params.value) {
        element.value += char;
        element.dispatchEvent(new Event('input', { bubbles: true }));
        await sleep(50); // 模拟打字速度
    }

    element.dispatchEvent(new Event('change', { bubbles: true }));
}
```

## 八、脚本导出

### 导出格式

| 格式 | 说明 | 用途 |
|------|------|------|
| JSON | 原生脚本格式 | WebChat 内部使用、分享 |
| JavaScript | 可独立运行的 JS 文件 | 在浏览器控制台执行 |

### 导出方式

由于 Chrome 扩展无法直接写入文件系统，使用以下方案：

1. **下载 API** — `chrome.downloads.download()` 将脚本保存到下载目录
2. **用户选择目录** — 使用 File System Access API（需要用户授权）让用户选择保存目录

```javascript
// 方案1：下载到指定文件夹
async function exportScript(script, format) {
    const content = format === 'json'
        ? JSON.stringify(script, null, 2)
        : generateJavaScript(script);

    const blob = new Blob([content], { type: 'application/json' });
    const url = URL.createObjectURL(blob);

    await chrome.downloads.download({
        url: url,
        filename: `webchat-scripts/${script.meta.name}.${format}`,
        saveAs: false
    });
}
```

## 十二、我的一些想法和建议

### 关于录制 + AI 的结合

建议实现"AI 增强录制"模式：
- 录制时 AI 实时分析用户操作意图
- 自动补充等待步骤和断言
- 将重复操作识别为循环
- 为录制的步骤生成更好的描述

### 关于脚本的可维护性

- 支持"子脚本"概念 — 将常用操作（如登录）封装为可复用的子脚本
- 支持脚本版本管理 — 记录每次修改历史
- 支持脚本模板 — 预设常见场景模板（表单填写、数据采集、页面测试）

### 关于执行的可靠性

- 选择器容错 — 主选择器失败时自动尝试备选选择器
- 智能等待 — 不使用固定延时，而是等待元素实际可交互
- 执行回放 — 记录每步执行的截图，方便调试失败的脚本

### 关于安全性

- 脚本执行前需要用户确认
- 敏感操作（如输入密码、支付）需要二次确认
- 脚本不应能访问扩展的 API 密钥等敏感配置
